## 💼 Featured Projects

### 🎓 [SWST-32043 University Course Registration Portal](https://github.com/Pasindu01262/SWST-32043-Mini-Project)

A full-stack MERN application that digitizes university course registration and administration. The role-based platform helps students quickly enroll in relevant courses while administrators manage courses, lecturers, grades, and student records.

**My contribution:** Developed the Course Management module by implementing CRUD operations, RESTful APIs, and MongoDB integration using the MERN stack.

Tech Stack: `React` `Vite` `React Router DOM` `Axios` `Node.js` `Express.js` `MongoDB Atlas` `Mongoose` `JWT` `bcryptjs`

📌 Collaborative academic project with feature-branch development, Postman testing, code review, and GitHub-based integration.

### 🚗 [Apex Auto Service System](https://github.com/Pasindu-CT56/Apex-Auto-Service-System)

A full-stack vehicle service booking platform with a customer portal and admin panel. Customers can browse services, book appointments, and track booking updates, while administrators can manage services, users, bookings, and statuses.

Tech Stack: `HTML5` `CSS3` `Vanilla JavaScript` `Supabase` `PostgreSQL` `date-fns`

📌 Full-stack web application with authentication, role-based access control, and real-time updates.

### 🌿 [ReGen - Waste Management and Recycling Application](https://github.com/Abhey518/Regen-waste-management-mobile-application)

A mobile-based waste management and recycling application built to encourage sustainable disposal habits and community engagement. The application includes garbage collection tracking, illegal dumping reports, environmental education, and rewards.

Tech Stack: `Flutter` `Dart` `Supabase` `PostgreSQL` `Flutter Map` `YOLOv8`
